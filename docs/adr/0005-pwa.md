# ADR-0005: An installable PWA at app.figlock.com

- Status: Superseded by ADR-0020
- Date: 2026-11-03
- Decision: D5 in `docs/decisions.md`

## Context

Users want access from any browser without installing, and an installable web app also covers devices without a native app. The risk is that whoever serves the JavaScript can change it (PRD risk table, threat model W1).

## Decision

Ship a PWA at app.figlock.com built from the WASM core, with a strict CSP, immutable deploys and a visible build hash. Power users are pointed to the extension or desktop app for stronger guarantees.

## Consequences

- The web app is a convenience tier, not the most trusted client, and the docs say so.
- WASM memory and threading limits affect Argon2 (see `crypto.md` 14).
- The site and the app are deployed from the same monorepo with path-filtered CI.

## Alternatives considered

- No web app: loses the no-install access and a fast way to onboard.
- Web only: contradicts the native-first mobile decision (ADR-0004).
