| D27 | 2026-11-12 | Each device stores the Secret Key | Secret Key shown once at creation, then kept in each device's store (tier 1 hardware plus presence, tier 2 OS login store, tier 3 owner-only file, every platform at least tier 2) and passed to new devices by pairing; typing it from the Emergency Kit is the fallback; Recovery Key is a required choice at setup; remote pairing approval is phase 2; OS cloud keychain rejected; no crypto or format change (FIG-100) | [0027](adr/0027-device-stores-the-secret-key.md) |

| D29 | 2026-11-13 | Recovery Key code and vault.json members | Single code is `FLR1-` + 14 groups of 4 base32 characters (32 key bytes + 3 check bytes), vectors in `recovery-key.json`; `vault.json` gets optional `rk_pub` and `wrapped_vk_rk` (both or neither, signed), rewrapped on every `VK` rotation; enabling or replacing needs the master password and Secret Key, removing needs neither in the core, the desktop app still asks for the master password; recovery sets a new password and Secret Key in one write (FIG-103) | [0029](adr/0029-recovery-key-code-and-vault-json-members.md) |
| D30 | 2026-11-13 | Unlocked desktop session holds the Secret Key | While unlocked, the desktop holds the Secret Key it unlocked or joined with (when the device does not keep one) in zeroizing memory, dropped on lock; steps that rewrap the vault key use typed, then held, then kept, then ask; the master password is still asked each time; nothing cached beyond the session; CLI unchanged; no crypto or format change (FIG-107) | [0030](adr/0030-session-holds-the-secret-key.md) |
| D31 | 2026-11-14 | Keychain items readable by any app of our team | Device keys, Secret Key and quick unlock key items are created with a read permission that trusts any application, so the partition list (`teamid:<team>`) decides: the signed CLI and desktop app share them with no prompt, other apps are still prompted; one helper in `figlock-biometric`; older items are replaced on next write; shared access group and separate device identities rejected (FIG-106) | [0031](adr/0031-keychain-items-shared-by-the-team.md) |
