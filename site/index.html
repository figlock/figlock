One vault for you and your agents

FigLock keeps your passwords, API tokens and notes in one encrypted vault that lives in storage you already own. When an AI agent needs a token, you approve it with Touch ID and the agent uses it without seeing it.

Install FigLock How it works

Built around three promises

  • Your storage, not ours

    The vault is ciphertext in Google Drive, iCloud Drive or a folder you choose. We don't run a server or a database that holds your data.

  • Agents use, they don't hold

    By default FigLock adds the token to the agent's web request itself. It can also inject the token into a command and scrub it from the output. Showing a raw value is opt-in per item and needs its own approval every time.

  • Open and standard

    Free, and licensed MIT or Apache-2.0. Only standard cryptography, written down with test vectors, and an outside audit before we invite other people to rely on it.

How it works

  1. Create a vault with two secrets

    Your master password plus a Secret Key that stays on your devices. You save the Secret Key in an Emergency Kit, and we ask you to check you saved it.

  2. Pick where it lives

    Choose Google Drive, iCloud Drive or another synced folder. Titles, URLs and usernames are encrypted too, so the provider sees only file counts, sizes and times.

  3. Find things fast, on any device

    Search is local and forgives typos, so "clodflare" still finds Cloudflare. Every device keeps its own encrypted copy and works offline.

  4. Let an agent work without handing over the key

    The agent asks, you approve for a limited time and scope, and every use goes into an encrypted audit log you can read.

Install it in a minute

FigLock 0.1 is the command line. Pick one of these, then run figlock --help.

  • Homebrew on macOS 

    brew install figlock/tap/figlock

    Installs the signed and notarized build for Apple silicon and Intel. Update it later with brew upgrade figlock.

  • The installer for macOS and Linux 

    curl -fsSL https://figlock.com/install.sh | sh

    Picks the right build for your machine and installs to ~/.local/bin. No admin rights needed.

  • The installer checks the download against its published SHA-256 checksum and stops if they don't match.
  • The macOS build is signed with a Developer ID and notarized by Apple.
  • You can read the installer before you run it.

Then, in four commands

figlock init --store ~/Documents/figlock-vault
figlock add --type login --title GitHub --set username=ada --secret password
figlock find github
figlock copy github

What's next

The command line comes first because agents live in terminals. The apps follow, in this order. We have no dates yet. Each one ships when it is ready and has been checked, and every one uses the same core and the same encryption as the command line.

Command line

Available now

Create a vault, add and find items, and let an agent use a secret after you approve it. Quick unlock with Touch ID, Apple Watch or your device password on a Mac.

  • macOS (Apple silicon and Intel)
  • Linux (x86_64 and ARM64), lightly tested so far
  • Vault in a folder you sync. Google Drive sign-in is waiting for Google's approval
Install

    Planned

    • Search that forgives typos
    • Approve agent requests with Touch ID
    • Password generator and a health report

  • iPhone app

    Planned

    Your vault on your phone, with autofill in apps and Safari and approvals for agents running on your computer.

    • Unlock with Face ID or Touch ID
    • AutoFill for passwords and tokens
    • Approve agent requests from your phone

  • Android app

    Planned

    The same vault on Android, with the system autofill service and your fingerprint or face to unlock.

    • Autofill in apps and the browser
    • Unlock with fingerprint or face
    • Sign-in with Credential Manager

Also planned

A browser extension with autofill and saving new logins, and more places to keep your vault, such as Git and S3. There is no hosted web version by design, so there is no website that holds your vault or asks for your master password.

Where we are

FigLock is an early release. Version 0.1 is the command line for macOS and Linux, and it has had no security audit yet. Please don't store real secrets in anything built from it until the audit is done and published. The apps above are planned and not built yet.
