Three promises

A quieter way to keep secrets.

No server of ours, no account to create, and nothing handed to an agent that it doesn't need.

  • Your storage, not ours

    The vault is ciphertext in Google Drive, iCloud Drive or a folder you choose. We don't run a server or a database that holds your data.

  • Agents use, they don't hold

    By default FigLock adds the token to the agent's web request itself. It can also inject the token into a command and scrub it from the output. Showing a raw value is opt-in per item and needs its own approval every time.

  • Open and standard

    Free, and licensed MIT or Apache-2.0. Only standard cryptography, written down with test vectors, and an outside audit before we invite other people to rely on it.

How it works

Set up once. Then forget it.

A good first five minutes, one choice at a time.

  1. Create a vault with two secrets

    Your master password plus a Secret Key that stays on your devices. You save the Secret Key in an Emergency Kit, and we ask you to check you saved it. You also choose a Recovery Key, so a forgotten password is not the end of your vault.

  2. Pick where it lives

    The vault always lives in a folder on your computer. Keep it in iCloud Drive or another synced folder, or turn on Google Drive sync in one step. Titles, URLs and usernames are encrypted too, so the provider sees only file counts, sizes and times.

  3. Find things fast, on any device

    Search is local and forgives typos, so "clodflare" still finds Cloudflare. Every device keeps its own encrypted copy and works offline. Add another device by approving it from one you already trust, and remove a lost one in a click.

  4. Let an agent work without the key

    The agent asks, you approve for a limited time and scope, and every use goes into an encrypted audit log you can read.

Built for agents

Your agent can use a secret. It can't keep it.

Start the broker and an agent asks for access. FigLock draws the prompt itself, never the agent, and names exactly what will happen. You approve with Touch ID, for a limited time and only for hosts you list.

  • Broker HTTP calls, with the token added for the agent
  • Or inject it into a command and scrub it from the output
  • Reveal is opt-in per item and needs its own approval every time

What you get today

Everything in one calm place.

The Mac app and the command line open the same vault and use the same encryption, so you can use whichever fits the moment.

  • Passwords, tokens and notes

    Logins, API tokens, notes and documents with files attached. Search forgives typos, deleted items go to a trash you can restore from, and the generator makes passwords and passphrases with a strength meter.

  • Quick unlock

    Unlock with Touch ID, your Apple Watch or your device password. Your Secret Key stays on the Mac, and the app locks itself when you step away or the Mac sleeps. You choose how soon.

  • Sync you control

    Optional Google Drive sync keeps an encrypted copy in a hidden app folder, and works offline. You can turn it off, sign in with another account, or delete the Drive copy with a typed confirmation.

  • Many devices, no surprises

    Add a device by approving it with Touch ID on one you already have, see every paired device, and revoke one at once. A revoked device is told, so it never silently loses work.

  • Recovery that is yours

    An Emergency Kit and a Recovery Key you can split into shares for people you trust. Forgot your password or Secret Key? The app walks you through the way back in.

  • Password health

    A report on weak, reused and old passwords, with an opt-in breach check that never sends your passwords anywhere.

  • Agent broker

    Start the broker and agents can call an API with your token added for them, or run a command with the token injected and scrubbed from the output. Approvals are time-boxed, limited to hosts you list, and logged.

  • Updates you click

    The Mac app checks a signed feed and installs a new version only when you say so. The command line is one brew upgrade away.

  • Command line inside

    The app can install the figlock command for you, so scripts and agents work against the same vault from a terminal.

Install

Install it in a minute.

Download the Mac app, or install the command line with Homebrew or the installer, then run figlock --help.

  • The Mac app

    Download FigLock 0.5.0

    A signed and notarized disk image for Apple silicon and Intel, with the command line inside. It updates itself when you choose.

  • Homebrew on macOS 

    brew install figlock/tap/figlock

    Installs the signed and notarized build for Apple silicon and Intel. Update it later with brew upgrade figlock.

  • The installer for macOS and Linux 

    curl -fsSL https://figlock.com/install.sh | sh

    Picks the right build for your machine and installs to ~/.local/bin. No admin rights needed.

  • The installer checks the download against its published SHA-256 checksum and stops if they don't match.
  • The macOS build is signed with a Developer ID and notarized by Apple.
  • You can read the installer before you run it.

Then, in four commands

figlock init --store ~/Documents/figlock-vault
figlock add --type login --title GitHub --set username=ada --secret password
figlock find github
figlock copy github

Honest status

Where we are.

FigLock is an early release. Version 0.5 is the Mac app and the command line, and it has had no outside security audit yet. Please don't store real secrets in anything built from it until the audit is done and published. The iPhone app is in beta and not released yet, and the Android app is planned and not built yet.
