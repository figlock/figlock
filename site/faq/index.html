Frequently asked questions

Last updated 25 November 2026. FigLock 0.5 is an early release: the Mac app and the command line. The iPhone app is in beta.

What is FigLock?

FigLock is a free, open-source password and secrets manager. It keeps your passwords, API tokens and notes in one encrypted vault that lives in storage you already own. AI agents can use a secret after you approve it, without seeing it. Today it is a Mac app and a command line tool.

Is FigLock free and open source?

Yes. FigLock is free software, dual licensed MIT or Apache-2.0, and the source is on GitHub. There are no FigLock accounts and nothing to subscribe to. See the source on GitHub.

Where is my vault stored?

Your vault is a set of encrypted files. A full copy sits on each of your devices, and the same files are kept in the storage you choose: Google Drive, iCloud Drive, or a folder you sync yourself. We run no server or database that holds your vault.

Can FigLock or my storage provider read my vault?

No. Everything is encrypted on your device with keys derived from your master password and your Secret Key, and we never receive either. Item titles, URLs and usernames are encrypted too. Your storage provider sees encrypted files, how many there are, how big they are and when they changed, and nothing else. More on what we store and who can see it.

What if I forget my master password?

You save your Secret Key in an Emergency Kit when you set up, and you also choose a Recovery Key, so a forgotten password is not the end of your vault. We can't reset your password for you, because we don't have it. If you lose both your master password and your Secret Key, the data can't be recovered.

How can an AI agent use a secret without seeing it?

You start the broker and the agent asks for access. FigLock draws the prompt itself, never the agent, and names exactly what will happen. You approve with Touch ID, for a limited time and only for hosts you list. The broker then adds the token to the agent's HTTP requests for it, or injects it into a command and scrubs it from the output.

Can an agent ever see my secret?

Only if you choose to reveal it. Reveal is opt-in per item and needs its own approval every time. Approving an agent only limits what the agent is handed, and a revealed secret can still end up in an agent's transcript, so reveal sparingly.

Which devices does FigLock run on?

The Mac app runs on Apple silicon and Intel Macs. The command line runs on macOS and Linux (x86_64 and ARM64), and the Linux builds are lightly tested so far. The iPhone app is in beta and coming soon. An Android app, a browser extension and Windows are planned. There is no hosted web version by design, so no website holds your vault or asks for your master password.

How do I install FigLock?

Download the Mac app from the install page, or install the command line with Homebrew using brew install figlock/tap/figlock, or with the installer script for macOS and Linux. The Mac app updates itself when you click, and the command line updates with brew upgrade figlock. See the install guide.

Has FigLock been security audited?

Not yet. FigLock 0.5 is an early release and has had no outside security audit. Please don't store real secrets in it until the audit is done and published.

Does this website track me?

No. These pages are plain static files with no cookies, no analytics and no scripts or fonts from other sites.

How do I report a security problem?

Write to security@figlock.com. Please don't include real vault data, tokens or recovery codes in a report.

Still have a question?

Ask in GitHub Discussions, or write to support@figlock.com.
