Install FigLock

Version 0.5.0: the Mac app, and the command line for macOS and Linux.

Pick one way below. Each takes about a minute, and then you can create a vault in about five.

This is an early release and it has had no security audit. Please don't store real secrets in it until the audit is done and published.

The Mac app

Download FigLock 0.5.0 for Mac

Open the disk image and drag FigLock to Applications. It is signed and notarized, runs on Apple silicon and Intel Macs, and has the command line inside: Settings > Command line tool installs figlock for you. The app checks for updates at launch and installs one only when you click. Create a vault in the app, or open an existing one, and add this Mac to it with a device invite.

Homebrew (macOS, command line)

brew install figlock/tap/figlock

This installs the signed and notarized build, which runs on Apple silicon and Intel Macs, and puts figlock on your path.

The installer (macOS and Linux, command line)

curl -fsSL https://figlock.com/install.sh | sh

The installer does five things, and nothing else:

  1. Works out your system and processor.
  2. Downloads the matching build and the list of official checksums.
  3. Checks the download against its SHA-256 checksum, and stops if it doesn't match.
  4. Puts figlock in ~/.local/bin.
  5. Tells you if that folder isn't on your path yet.

It never asks for admin rights. You can read the installer before you run it. To choose a version or a folder:

curl -fsSL https://figlock.com/install.sh | FIGLOCK_VERSION=v0.5.0 FIGLOCK_INSTALL_DIR="$HOME/bin" sh

Download it yourself

Every build and the checksum list are on the latest release page. Pick the file for your machine:

MachineFile
Mac, Apple silicon or Intelfiglock-0.5.0-universal-apple-darwin.tar.gz
Linux, x86_64figlock-0.5.0-x86_64-unknown-linux-musl.tar.gz
Linux, ARM64figlock-0.5.0-aarch64-unknown-linux-musl.tar.gz

Check the file against the list, then unpack it. On Linux use sha256sum in place of shasum -a 256.

grep figlock-0.5.0-universal-apple-darwin.tar.gz SHA256SUMS | shasum -a 256 -c
tar -xzf figlock-0.5.0-universal-apple-darwin.tar.gz && ./figlock --version

Check it works

figlock --version

You should see figlock 0.5.0. If your shell says command not found, add the install folder to your path:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && exec zsh

Your first five minutes

  1. Create a vault

    Pick a folder on this Mac and, if you like, sync it to iCloud Drive or Google Drive. FigLock shows your Secret Key and helps you save an Emergency Kit. Keep it safe: without the kit and your master password, nobody can open your vault, including us. On a Mac it then asks whether to unlock this device with Touch ID; press Enter for yes.

    figlock init --store ~/Documents/figlock-vault

  2. Add something

    The password is asked for on the screen, never on the command line, so it stays out of your shell history.

    figlock add --type login --title GitHub --set username=ada --secret password

  3. Find it and use it

    Search forgives typos. Copying clears your clipboard after 30 seconds.

    figlock find github
    figlock copy github

  4. Quick unlock (Mac)

    Unlock with Touch ID, your Apple Watch or your device password instead of typing your master password every time. Your Secret Key stays on this Mac either way; with quick unlock on it is tied to your Mac's chip. Create asks you about it; if you said no, or want it on a vault you already have, turn it on here. figlock quick-unlock disable turns it off.

    figlock quick-unlock enable

  5. Change your password or Secret Key later

    Both ask for your current details first. Other devices then ask for a full unlock with the new ones. Rotating the Secret Key shows the new one once, so replace your Emergency Kit.

    figlock password change
    figlock secret-key rotate

  6. Let an agent use a token

    Add a token item, then run a program with it. You approve the request first, and the agent never sees the token.

    figlock add --type token --title "API key" --set provider=example --set env_var=EXAMPLE_TOKEN --set allowed_hosts/1=api.example.com --secret token
    figlock broker start
    figlock run --item "API key" -- ./deploy.sh

Every command explains itself: run figlock --help, or figlock add --help to see the fields each kind of item takes.

Keep your vault in Google Drive

Google Drive sync is optional and can be turned on or off at any time, in the app (Settings > Google Drive sync) or with the commands below. Your vault stays in a local folder on your Mac and FigLock keeps an encrypted copy in Drive. It only gets a hidden app folder, never your files, and everything in it is encrypted before it leaves your Mac.

figlock drive login
figlock init --drive

Keep your vault in iCloud Drive

On a Mac, FigLock can keep an encrypted copy in a folder called FigLock in your iCloud Drive. There is nothing to sign in to: iCloud Drive just has to be on (System Settings > your name > iCloud > Drive). Turn it on in the app (Settings > iCloud Drive sync) or with the commands below. It works on its own or together with Google Drive, and each can be turned off without touching the other.

figlock init --icloud
figlock sync on --icloud
figlock sync off --icloud
figlock sync status

iCloud Drive is Apple-only, so it does not work on a headless Linux server: use Google Drive there, or --sync-folder <path> for any other synced folder such as Dropbox or Syncthing. With Optimize Mac Storage on, iCloud may keep the vault only in the cloud until it is needed, and FigLock downloads it when it needs it. When a second Mac joins a vault that is still arriving through iCloud, FigLock says it is waiting for iCloud to finish and tries again; it never reports a missing vault for a folder that is only partly downloaded. Leave the files in the FigLock folder alone.

Add a second device

Install FigLock on the new device, then pair it with one that already has your vault. Start on the device that has the vault:

figlock device add

It shows an invite code and waits. On the new device, run join with that code and point it at the same vault: the synced folder, --icloud for a vault in iCloud Drive, or --drive for a vault in Google Drive.

figlock join CODE --store ~/Documents/figlock-vault

The new device shows a fingerprint. Check that the same fingerprint appears on the first device, then approve it there. The new device then asks for your master password. You don't need to type your Secret Key, because the approval carries it. The code works once and expires after 10 minutes. If it is never approved, nothing is added.

If no device that has the vault is at hand, use your Emergency Kit instead. This asks for your master password and Secret Key:

figlock open --store ~/Documents/figlock-vault

Update and remove

The Mac app updates from Settings when you click. For the command line, run brew upgrade figlock or run the installer again. To remove the command line:

brew uninstall figlock
rm ~/.local/bin/figlock

Removing the program leaves your vault and your settings alone. The vault is in the folder or the Drive you chose, so you can install again at any time and carry on.

Something wrong?

If a checksum doesn't match, don't use the file: download it again, and if it still fails, tell us. To report a security problem, write to security@figlock.com.
