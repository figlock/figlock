Install FigLock

Version 0.1.0, the command line for macOS and Linux.

Pick one way below. Each takes about a minute, and then you can create a vault in about five.

This is an early release and it has had no security audit. Please don't store real secrets in it until the audit is done and published.

Homebrew (macOS)

brew install figlock/tap/figlock

This installs the signed and notarized build, which runs on Apple silicon and Intel Macs, and puts figlock on your path.

The installer (macOS and Linux)

curl -fsSL https://figlock.com/install.sh | sh

The installer does five things, and nothing else:

  1. Works out your system and processor.
  2. Downloads the matching build and the list of official checksums.
  3. Checks the download against its SHA-256 checksum, and stops if it doesn't match.
  4. Puts figlock in ~/.local/bin.
  5. Tells you if that folder isn't on your path yet.

It never asks for admin rights. You can read the installer before you run it. To choose a version or a folder:

curl -fsSL https://figlock.com/install.sh | FIGLOCK_VERSION=v0.1.0 FIGLOCK_INSTALL_DIR="$HOME/bin" sh

Download it yourself

Every build and the checksum list are on the latest release page. Pick the file for your machine:

MachineFile
Mac, Apple silicon or Intelfiglock-0.1.0-universal-apple-darwin.tar.gz
Linux, x86_64figlock-0.1.0-x86_64-unknown-linux-musl.tar.gz
Linux, ARM64figlock-0.1.0-aarch64-unknown-linux-musl.tar.gz

Check the file against the list, then unpack it. On Linux use sha256sum in place of shasum -a 256.

grep figlock-0.1.0-universal-apple-darwin.tar.gz SHA256SUMS | shasum -a 256 -c
tar -xzf figlock-0.1.0-universal-apple-darwin.tar.gz && ./figlock --version

Check it works

figlock --version

You should see figlock 0.1.0. If your shell says command not found, add the install folder to your path:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && exec zsh

Your first five minutes

  1. Create a vault

    Pick a folder you already sync, or use Google Drive. FigLock shows your Secret Key and helps you save an Emergency Kit. Keep it safe: without the kit and your master password, nobody can open your vault, including us. On a Mac it then asks whether to unlock this device with Touch ID; press Enter for yes.

    figlock init --store ~/Documents/figlock-vault

  2. Add something

    The password is asked for on the screen, never on the command line, so it stays out of your shell history.

    figlock add --type login --title GitHub --set username=ada --secret password

  3. Find it and use it

    Search forgives typos. Copying clears your clipboard after 30 seconds.

    figlock find github
    figlock copy github

  4. Quick unlock (Mac)

    Unlock with Touch ID, your Apple Watch or your device password instead of typing your master password and Secret Key every time. The key is tied to your Mac's chip. Create asks you about it; if you said no, or want it on a vault you already have, turn it on here. figlock quick-unlock disable turns it off.

    figlock quick-unlock enable

  5. Let an agent use a token

    Add a token item, then run a program with it. You approve the request first, and the agent never sees the token.

    figlock add --type token --title "API key" --set provider=example --set env_var=EXAMPLE_TOKEN --set allowed_hosts/1=api.example.com --secret token
    figlock broker start
    figlock run --item "API key" -- ./deploy.sh

Every command explains itself: run figlock --help, or figlock add --help to see the fields each kind of item takes.

Keep your vault in Google Drive

A folder you sync yourself, such as one in iCloud Drive or Dropbox, works today. Google Drive support is built, but Google is still approving FigLock's sign-in, so it may not work for you yet. When it does, FigLock only gets a hidden app folder in your Drive, never your files, and everything in it is encrypted before it leaves your Mac.

figlock drive login
figlock init --drive

Update and remove

To update, run brew upgrade figlock, or run the installer again. To remove it:

brew uninstall figlock
rm ~/.local/bin/figlock

Removing the program leaves your vault and your settings alone. The vault is in the folder or the Drive you chose, so you can install again at any time and carry on.

Something wrong?

If a checksum doesn't match, don't use the file: download it again, and if it still fails, tell us. To report a security problem, write to security@figlock.com.
